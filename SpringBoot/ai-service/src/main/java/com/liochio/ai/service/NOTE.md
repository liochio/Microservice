# Package com.liochio.ai (Controller, DTO, Entity, Repository, Service)

## Controller ('com.liochio.ai.controller')
- 'AiController': Tiếp nhận phiên chat, gửi tin nhắn tới bot, nạp tri thức và cấu hình Tenant AI.

## Entity ('com.liochio.ai.entity')
- 'AiChatSessionEntity', 'AiChatMessageEntity', 'AiKnowledgeBaseEntity', 'TenantAiConfigEntity', 'AiPromptEntity'.

## Service ('com.liochio.ai.service')
- 'AiService': Xử lý giao tiếp OpenAI API, quản lý bộ nhớ đệm ngữ cảnh và cơ sở tri thức tài liệu.
