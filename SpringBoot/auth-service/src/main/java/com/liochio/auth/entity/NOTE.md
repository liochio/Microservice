# Package: com.liochio.auth.entity

## 1. Vai trò & Chức năng
- Định nghĩa cấu trúc các bảng ánh xạ trong cơ sở dữ liệu cho Auth Service.

## 2. Các thành phần chính
- 'UserEntity.java': Ánh xạ bảng 'users'.
- 'RoleEntity.java': Ánh xạ bảng 'roles'.
- 'PermissionEntity.java': Ánh xạ bảng 'permissions'.
- 'UserTokenEntity.java': Ánh xạ bảng 'user_tokens'.
