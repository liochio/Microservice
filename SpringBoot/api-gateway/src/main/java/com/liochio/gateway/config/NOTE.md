# Package: com.liochio.gateway.config

## 1. Vai trò & Chức năng
- Quản lý cấu hình Cross-Origin Resource Sharing (CORS) cho API Gateway.

## 2. Các thành phần chính
- 'GatewayCorsConfig.java': Cho phép tất cả các nguồn gốc (Origin Patterns), hỗ trợ đầy đủ các phương thức HTTP và headers cần thiết.
