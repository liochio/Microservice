# Package: com.liochio.media.adapter

## 1. Vai trò & Chức năng
- Cung cấp các triển khai cụ thể của giao diện `StorageStrategy`.

## 2. Các thành phần chính
- `LocalStorageAdapter.java`: Lưu trữ tệp tin trên ổ đĩa máy chủ và xử lý ghép nối các chunk tệp tin.
- `CloudinaryStorageAdapter.java`: Lưu trữ và phân phối hình ảnh qua mạng CDN Cloudinary.
