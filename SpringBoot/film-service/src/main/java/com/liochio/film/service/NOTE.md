# Package com.liochio.film (Controller, DTO, Entity, Repository, Service)

## Controller (`com.liochio.film.controller`)
- `FilmController`: Quản lý danh mục phim, tìm kiếm theo thể loại, tra cứu tập phim và link server phát video.

## Entity (`com.liochio.film.entity`)
- `MovieEntity`, `MovieGenreEntity`, `MovieEpisodeEntity`, `StreamingServerEntity`, `MovieReviewEntity`, `MovieCastEntity`.

## Service (`com.liochio.film.service`)
- `FilmService`: Xử lý nghiệp vụ quản lý phim, tổng hợp đánh giá và cung cấp link streaming tối ưu theo vùng địa lý.
