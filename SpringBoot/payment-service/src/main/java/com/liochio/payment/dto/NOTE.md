# Package: com.liochio.payment.dto

## 1. Vai trò & Chức năng
- Định nghĩa các đối tượng truyền tải dữ liệu Request / Response cho Payment Service.

## 2. Các thành phần chính
- `CreatePaymentRequest.java`: DTO yêu cầu tạo URL thanh toán.
- `PaymentUrlResponse.java`: DTO trả về link cổng thanh toán.
- `PaymentOrderResponse.java`: DTO chi tiết đơn hàng thanh toán.
