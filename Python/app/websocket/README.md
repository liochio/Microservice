# WebSocket Realtime Communication Package

## Chức năng
Gói pp/websocket quản lý kết nối 2 chiều thời gian thực (Full-duplex WebSocket):
1. **Realtime Balance Updates**: Đẩy biến động số dư ví tức thì lên giao diện người dùng.
2. **Smart Piggy Status**: Trực quan hóa trạng thái heo đất IoT (đang nạp tiền, đang mở khóa).
3. **Push Notifications**: Cập nhật thông báo hệ thống và cảnh báo chi tiêu không độ trễ.
